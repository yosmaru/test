# もみの木ハウスの考え方と質問の対照表（手元用・B社には見せない）

| もみの木ハウスのやり方・考え方 | B社への質問 |
|---|---|
| **Q02 建てた後のコスト**<br>・「建てた後にお金がかからない家」を一番のテーマにしている<br>・外壁・屋根はメンテナンスの周期が長いもの（外壁25年、屋根25〜30年）を選び、周期をそろえて足場を1回で済ませる<br>・床暖房、全館空調、太陽光（新潟の場合）、バルコニーは勧めない（例: 全館空調は交換に150〜300万円、床暖房の床の張り替えの見積もりは400万円）<br>・光熱費の比較: 同社で建てた家は11月で1.5万円、社長の仮住まい（他社が建てた家）は6.3万円 | 建てた後にかかるお金（光熱費、メンテナンス、設備の交換など）は、設計の段階でどのように考えていますか？30年間でどのくらいかかる見込みか示してもらえますか？<br><br>深掘り: 外壁・屋根・主な設備は、それぞれ何年ごとに、どのくらいの費用がかかる想定ですか？／住んでいるお客様の年間の光熱費はどのくらいですか？ |
| **Q05 施工品質**<br>・仕様を1種類に絞り、断熱材などを施主に選ばせない（選択肢が多い会社は経験が分散する）<br>・自社で大工を育て（大工を4年経験してから設計へ）、工程ごとに3〜4回チェックする<br>・気密は全棟で測る。工事中に第三者が測り、漏れている所を探して直す（完成時C値0.28、工事中に0.09の例）<br>・壁を閉じる前に第三者が検査する<br>・夏冬は現場にエアコンを置き、資材は雨から守り、季節に合わせて施工のやり方を変える | 現場の施工品質はどのように管理していますか？誰が、いつ、何をチェックしますか？<br><br>深掘り: 大工さんは社内の方ですか、外部の方ですか？現場監督は同時に何棟くらいを担当しますか？／壁を閉じる前の状態を施主が見学したり、写真の記録をもらったりできますか？ |
| **Q09 換気**<br>・第3種換気（排気だけ機械で行う方式）を使う。手入れはフィルター掃除だけで済む。熱交換型の第1種換気はカビやメンテナンスの手間を理由に使わない<br>・空気の流れは間取りの最初に決める。エアコンのある空間から空気を入れ、空気を流したい部屋から出す<br>・空気は外壁の内側の空気層から取り込む（花粉・虫・外壁の傷みへの対策）<br>・「24時間換気をすれば家中の空気が入れ替わる」は思い込みで、家の隙間が少ないことが前提<br>・エアコンは計算で容量を出し、壁掛け1台で家全体をまかなう（夏は2階、冬は1階の機械を使う）。個室にはつけない | 冷暖房と換気は、家全体でどのように計画していますか？エアコンの台数や容量は、どのように決めていますか？<br><br>深掘り: 換気の方式を選んだ理由と、住んでからのお手入れ（フィルター掃除・部品交換）の内容や費用を教えてください。／エアコンや換気設備を将来交換するとき、費用はどのくらいかかりますか？ |
| **Q08 湿気・カビ**<br>・湿気を吸ったり吐いたりする内装材（床・壁のもみの木）で、室内の湿度を50〜60%に保つ。水分をいったん吸い、換気で少しずつ外へ出す<br>・洗濯は洗面脱衣室で干し、その場でしまう<br>・収納に扉をつけず、空気を動かす。カビは「温度差」と「空気がよどむこと」で起きる<br>・ビニールクロスの防カビ剤は約10年で効かなくなる<br>・「間取りだけ真似すると危険」（同じ間取りを他社で建てた家でカビが出た実例あり）<br>・ファンヒーターや加湿器の水蒸気による結露にも注意 | 室内干しの洗濯物や、収納・家具の裏などの湿気・カビ対策は、どのように考えて設計していますか？<br><br>深掘り: 洗濯物から出た水分は、家の中でどこへ行き、どのように外へ出される設計ですか？／住んでいる方から結露やカビの相談を受けたことはありますか？どう対応しましたか？ |
| **Q13 間取り・生活動線**<br>・「リビングは何畳？」から始めない。人柄、身長、利き手、帰宅後の動き、買い物の頻度などを雑談しながら聞き取る<br>・要望には理由を聞き、必要ならやめることを勧める（和室やバルコニーをやめた施主の例）<br>・間取りは聞き取りをもとに会社が提案し、施主に見せる回数は確認のための1〜2回。打ち合わせはほとんどない<br>・ぐるっと回れる動線そのものを目的にしない。行き止まりや引き返しのない動き方にし、廊下は最小限にする<br>・子どもが巣立った後の夫婦二人の暮らしも考える | 間取りを考えるとき、最初に何をどのように聞き取りますか？施主の要望とプロとしての提案が違うときは、どうしますか？<br><br>深掘り: 要望をそのまま図面にするときと、理由を聞いて別の案を出すときは、どう使い分けていますか？／過去に、お客様の要望と違う提案をした例があれば教えてください。 |
| **Q15 収納**<br>・「収納は何畳いりますか？」ではなく、「誰の、何を、どこに置くか」を最初に決める<br>・収納は使う場所の近くに、扉のない形でつくる（パントリー、ウォークインクローゼット、シューズクローク）<br>・家族の服をまとめる部屋をつくり、洗う・干す・しまうを1か所で済ませる<br>・棚は高さを変えられるものにし、作り込みすぎない<br>・片付けられないのは人のせいではなく、間取りの仕組みのせい | 収納の量や配置、家事動線は、どのように設計していますか？<br><br>深掘り: 洗濯（洗う・干す・しまう）の流れや、帰宅してからの動きは、どこまで聞き取って設計しますか？／収納の扉の有無や棚の作り方は、どのような考えで決めていますか？ |
| **Q16 メンテナンス**<br>・外壁が長持ちするかは、材料よりも施工（外壁の内側の空気の通り道）で決まる。空気の入口（土台側）と出口（屋根の頂上側）の両方が必要で、出口のない家が多い<br>・外壁の材料は会社が選ぶ（ニチハのサイディングが標準）。流行に左右されない<br>・屋根と外壁のメンテナンス周期をそろえる。瓦は使わない<br>・バルコニーはつくらない（防水が難しく、排水口が凍ったり雪が積もったりして雨漏りの原因になる）<br>・屋根は切妻か片流れにして雨どいを減らし、家の形をシンプルにする<br>・引き渡し後は1・2・5・10年目に点検し、第三者と施工した人が一緒に見る | 外壁・屋根・バルコニーなど外まわりは、どのような基準で仕様を決めていますか？雨漏りや劣化を防ぐために、施工で気をつけている点は何ですか？<br><br>深掘り: 外壁と屋根のメンテナンス時期と費用の目安を教えてください。その際、足場は何回必要になりますか？／外壁の内側の空気の通り道（通気）は、どのように確保していますか？ |
