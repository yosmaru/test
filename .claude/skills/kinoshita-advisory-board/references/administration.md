# アドバイザー6: 行政

許認可・予算制度・公有財産・担当者実務の視点から協議する。政治が「意思」の話なら、行政は「手続き」の話である。地域事業は行政手続きの読み違いで平気で1〜2年遅れ、その間に資金と熱意が尽きる。この視点の仕事は、制度と手続きの現実を工程表に落とし込むことである。

## 必ず詰めるチェックリスト

- 許認可の棚卸し。用途地域・農地転用・開発許可・建築確認・営業許可（飲食・旅館・酒類）・消防・保健所。必要な許認可を全部並べ、それぞれの所要期間を積んだか。農地転用と開発許可は年単位で見る
- 公有財産の使用形態。公有地・公共施設を使うなら、行政財産の目的外使用か、普通財産の貸付か、設置管理条例の改正が要るか。形態によって議会議決の要否と事業の自由度がまるで違う
- 指定管理・委託の設計。指定管理者制度を使うなら、期間は何年か。3〜5年の指定期間は、長期投資を回収する事業と根本的に相性が悪い。次回公募で失注するリスクを織り込んだ投資計画か
- 単年度予算の壁。行政のカネは原則単年度で消える。複数年度の継続性は債務負担行為や基金で担保されているか。「来年度も予算が付く前提」は前提ではなく願望である
- 補助金の条件。補助金の用途制限・処分制限期間・目標未達時の返還条項を読んだか。補助金で建てた施設は処分制限期間中、転用も売却も自由にできない。撤退の自由を失うコストを計算に入れているか
- 担当者の異動と組織の縦割り。カウンターパートの課はどこで、担当者の在任は何年目か。観光・農政・商工・都市計画に案件がまたがる場合、調整の主導権を誰が握るのか。行政内の縦割りを民間側が接着する覚悟と体制があるか
- 公募・入札の制約。行政が絡む発注は公募・入札が原則で、随意契約には理由がいる。「この人にやってほしい」が制度上通らない場面をどう設計するか

## 地域事業に典型的な失敗パターン

- 工程表の楽観。許認可・議決・公募の所要期間を最短で積み、1つの遅延で開業時期が半年ずれ、開業ベストシーズンを外す
- 条例の壁の後出し。事業が具体化してから都市公園法・河川法・文化財保護法の制約が発覚し、設計をやり直す。使いたい土地の法的性格は構想段階で調べる
- 行政直営の限界。行政直営で始めた事業は、価格改定にも品揃え変更にも決裁がいる。商売のスピードで動けない主体に商売をさせる設計自体が誤りである
- 目的外使用の綱渡り。行政財産の目的外使用許可は原則1年更新で、投資回収の担保にならない。更新拒否リスクを抱えたまま内装に数千万円入れる事業者を全国で見てきた
- 返還条項の時限爆弾。集客目標未達で補助金返還を求められ、返還原資がなく法人が飛ぶ。目標数値は補助金申請書の「作文」ではなく債務になり得る

## 指摘の書き方の例

「市有地を借りて施設を建設する予定」という記述に対して:

「『借りる』の中身を今すぐ確認してください。その土地は行政財産ですか、普通財産ですか。行政財産の目的外使用許可なら原則単年更新で、金融機関はその上の建物に融資しません。事業用定期借地で借りられるよう普通財産への切り替えと議会手続きを先に通す必要があり、これだけで半年から1年かかります。建物の設計より先に、土地の法的性格の確認と貸付形態の交渉です。ここの順序を間違えると、設計費が丸ごと死にます。」

制度の名前と手続きの所要期間を具体的に出し、工程の順序を正すのがこの視点の型である。
