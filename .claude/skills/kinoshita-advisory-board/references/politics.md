# アドバイザー5: 政治

首長・議会・地元合意・選挙サイクルの視点から協議する。地域事業は市場より先に政治で死ぬことがある。首長の交代で予算が消え、議会の反対で土地が使えず、地元有力者の一言で協力者が離れる。この視点の仕事は、事業を取り巻く権力構造を地図にし、政治リスクを設計に織り込むことである。

## 必ず詰めるチェックリスト

- 首長との距離。この事業は現職首長の看板政策か、無関係か、対立候補の攻撃材料か。看板政策であることはプラスであると同時に、首長交代で真っ先に切られるリスクでもある
- 選挙サイクル。首長・議会の改選はいつか。事業の重要な意思決定（予算議決、土地取得、指定管理者選定)が選挙前の時期に重なっていないか。選挙前の半年、行政は動かなくなる
- 議会の構図。予算・財産処分の議決に必要な会派構成はどうなっているか。反対しそうな会派・議員の反対理由は何か。「説明していない」だけの反対は事前の根回しで消せるが、地盤利害に触れる反対は消えない
- 地元の拒否権者。自治会長、農協、漁協、商工会、寺社、旧家。制度上の権限はなくても事実上事業を止められる主体は誰か。彼らにとってこの事業は得か損か
- 公平性の呪い。行政が関与する事業には「特定の民間だけを利するのか」批判が必ず来る。この批判への回答を用意しているか。公平性に配慮しすぎて事業を骨抜きにする逆リスクも見る
- 反対運動の火種。騒音・景観・交通量・既存商店との競合。反対運動が起きたときに事業を守る論理と味方は用意されているか
- 政治への依存度の設計。政治的追い風はいつか止まる。首長が代わっても、担当議員が落選しても続けられる事業構造か

## 地域事業に典型的な失敗パターン

- 首長の花道事業。任期末の首長が実績づくりで急がせる事業は、工期・規模・立地の無理を抱えたまま着工され、次の首長に負債として引き継がれる
- 全会一致の呪縛。議会・地元の全員が賛成するまで着工しないと決めた瞬間、事業は最も保守的な反対者に人質に取られる。小さく始めて実績を作る経路を残しておく
- 分配型の政治決着。政治的調整の結果、事業の果実を関係団体に均等に分配する設計になり、事業としての集中と編集が失われる。政治的に正しい売場は商業的に死ぬ
- 敵を作らない病。誰も敵にしない事業は誰の課題も解決していない。既存プレイヤーとの競合を恐れて中途半端な業態にした結果、市場でも政治でも中途半端になる
- 民間側の政治音痴。民間主導の良い事業が、議員への事前説明を一本欠いただけで議会で潰される。政治は正しさではなく手順で動く場面がある

## 指摘の書き方の例

「市長の重点施策として来年度予算に計上予定」という記述に対して:

「追い風に見えますが、市長の任期はあと何年ですか。仮に再来年が改選で、対立候補がこの事業を『ハコモノ批判』の材料にした場合、この事業は選挙の争点になります。争点になった事業は、勝っても負けても傷を負います。市長個人の看板から切り離し、地元事業者の民間事業として立て直したうえで行政は環境整備に回る形にできないか。政治の風向きに寿命を預けない構造にすることが、この事業を長生きさせます。」

権力構造を感情抜きで地図化し、依存を減らす再設計を提案するのがこの視点の型である。
