# 召集アドバイザー（座長が案件に応じて招集）

常設8視点に加え、案件が特定の論点を抱えるときだけ座長が招集する専門アドバイザー。全案件で全員を並べると協議会が肥大し、木下斉自身が組織マネジメントで戒める「船頭多くして」に陥る。だから召集制にする。招集したときだけ、その視点を常設と同じ型（現状評価・死因候補・問い・次の一手）で協議する。招集しない視点は登場させない。

座長は冒頭所見で人名を挙げて招集を宣言してから協議に入る。「本件は台風リスクが重い。荒木田さんを呼びます」。各人の経歴と語り口は references/advisors-cast.md に従う。

## 召集トリガー表

| 召集アドバイザー | 招集するトリガー |
|---|---|
| 税務・会計 | 法人化を検討している、補助金を受給する、複数の事業主体・出資者がいる、利益配分が発生する |
| 人材・採用・承継 | 従業員を雇う計画がある、後継者・世代交代が論点、担い手そのものが事業の要 |
| オペレーション | 飲食・宿泊・小売など、日々の現場運営の質が収益を左右する |
| デジタル | 予約・決済・EC・SNS・データ活用が集客や業務効率の鍵になる |
| 地域社会・受容 | 移住者やよそ者が主体、住民との摩擦が予想される、公有地・里山・水などの共有資源を使う |
| 環境・防災 | 災害リスクの高い立地、自然資源が事業基盤、環境規制・脱炭素の要請がかかる |
| 建築 | 既存建物の改修・用途変更・新築を伴う、既存不適格や検査済証の有無が論点、工事費が投資の過半を占める |
| 土木 | 造成・地盤・排水・道路取り付け・上下水道の引き込みが絡む、大規模な駐車場や外構を計画している |
| デザイン | 商品パッケージ・ブランド・サイン・売場の「見え方」が競争力を左右する、リブランディングが論点 |

複数のトリガーに該当する案件では複数を招集してよい。ただし、常設8＋召集で協議録が長くなりすぎる場合は、召集分は現状評価と死因候補を厚く、問いと次の一手を絞る。

## 税務・会計（田淵幸三）

事業形態と税の設計を見る。ファイナンスがカネの出所と収支を見るのに対し、この視点は「稼いだあと、税と会計でいくら残り、どう申告するか」を見る。

チェックリスト:
- 事業形態の税務。個人事業か法人か。所得規模と将来の投資計画から、法人化の損益分岐（おおむね課税所得800万円前後が一つの目安）を試算したか
- 消費税とインボイス。課税事業者か免税事業者か。インボイス制度で取引先との関係が変わらないか
- 補助金の税務。補助金は原則として課税対象の収入になる。圧縮記帳の適用可否を含め、受給後の税負担を計算に入れたか
- 会計の分離。事業の会計と私生活の家計を分けているか（鉄則⑩の会計的裏付け）
- 減価償却と資金繰りのズレ。利益は出ているのに現金がない、という帳簿と現金の乖離を理解しているか

死因になる典型: 補助金を非課税と思い込み、翌年の納税で資金繰りが破綻する。法人化のタイミングを誤り、無駄な均等割・社会保険料を抱える。

## 人材・採用・承継（森本さゆり）

担い手を見る。地域の担い手消失は木下斉の中心テーマである。組織マネジメントが体制と意思決定を見るのに対し、この視点は「地域の労働市場で、実際に人を採れるのか、辞めないか、10年後に誰が継ぐのか」を見る。

チェックリスト:
- 採用可能性。計画上の人員を、地域の労働市場で、その賃金で実際に採れるのか。人口減少地域で若い働き手は希少で、都市部との賃金競争に負ける
- 定着。採った人が辞めない設計か。地域の中小事業は、育てた人材の流出（鉄則の連載テーマそのもの）で疲弊する
- 育成と権限移譲。中心人物の技能・関係性を、他の人に移せるか。キーパーソンに全依存していないか
- 事業承継。10年後、20年後に誰がこの事業を継ぐのか。承継の道筋がない事業は、創業者の引退が事業の終わりになる
- 報酬と処遇。地域相場と生活給の両方から見て、続けられる処遇か

死因になる典型: 事業は回っても人が採れず創業者が過労で倒れる。育てた若手が都市部に流出し、技能が承継されずに事業が先細る。

## オペレーション（権藤大地）

日々の現場が回るかを見る。計画は立っても、仕入れ・在庫・品質・シフト・提供スピードといった日々の運営が破綻して死ぬ事業は多い。特に飲食・宿泊・小売で効く。

チェックリスト:
- 提供能力。ピーク時に、その人員と設備で、計画上の客数を実際に捌けるのか。厨房の処理能力、客室の清掃回転、レジの列
- 仕入れと在庫。仕入れルート・リードタイム・ロス率。生鮮や季節商材の廃棄ロスを収支に織り込んだか
- 品質の安定。属人的な品質を、日によってぶれない水準で出せる仕組みがあるか。マニュアル・レシピ・チェックの標準化
- 稼働と生産性。人時生産性（1人1時間あたりの売上）は業態の相場に届くか
- 繁閑差への対応。平日と休日、季節の波に、固定費と人員をどう合わせるか

死因になる典型: 開業景気の行列を捌けず評判を落とす。廃棄ロスと人件費で、売上はあるのに利益が残らない。

## デジタル（早乙女玲）

予約・決済・集客・データの仕組みを見る。地方事業ほど手薄で、ここの設計次第で集客コストと業務効率が大きく変わる。マーケティングの販路と重なるが、システムとツールの設計を独立して詰める。

チェックリスト:
- 予約・決済。オンライン予約、キャッシュレス決済、OTA（宿泊予約サイト）連携を、手数料と手間の両面から設計したか
- 集客チャネル。検索（MEO・Googleビジネスプロフィール）、SNS、口コミサイト。どこで見つけてもらうかの導線があるか
- データ活用。顧客リスト、リピート施策、予約データの分析。一見客をリピーターに変える仕組みがあるか
- 業務効率化。会計・在庫・シフトのデジタル化で、少人数運営を成立させているか
- 身の丈のツール選定。高機能なシステムを入れて使いこなせず放置する、の逆をやれているか

死因になる典型: 電話とノートだけで回そうとして機会損失を垂れ流す。逆に過剰なシステムを導入して費用と運用負担に潰される。

## 地域社会・受容（嘉村八重）

地域からの社会的受容（ソーシャルライセンス）を見る。政治が権力構造を、行政が手続きを見るのに対し、この視点は「住民の感情と信頼」という、制度に現れない受容の土台を見る。移住者・よそ者が主体の事業では死活的である。

チェックリスト:
- 住民の感情。この事業を地元はどう受け止めるか。歓迎か、警戒か、無関心か。「よそ者が儲ける」という感情が生まれないか
- 信頼の蓄積。事業者は地域にどれだけ根を張っているか。挨拶、行事参加、地元での実績。信頼は一朝一夕には積めない
- 共有資源の扱い。里山・水・景観・道路など、地域の共有物を使う場合、地域への還元と説明があるか
- 既存プレイヤーとの関係。同業の地元事業者を敵に回していないか。共存の設計はあるか
- 情報の透明性。何をやろうとしているかを地域に開いているか。閉じた事業は憶測と反感を生む

死因になる典型: 移住者が良い事業を始めても、地元への挨拶と説明を欠いて孤立し、協力も客も得られない。共有資源の私物化と受け取られ反対運動が起きる。

## 環境・防災（荒木田守）

自然災害・環境・持続可能性のリスクを見る。地域は災害リスクに直結し、自然資源を基盤にする事業も多い。木下斉の連載でも大槌町の山火事や地域の防災力崩壊を扱っている。

チェックリスト:
- 災害リスク。立地はハザードマップ上どうか。洪水・土砂・津波・地震・火災の想定と、事業への影響。被災時の事業継続計画があるか
- 自然資源への依存。農林水産・観光など、天候・気候変動・資源枯渇に収益が左右される度合いと、その分散
- 環境規制と地域環境。排水・廃棄物・騒音・景観の規制。地域の自然環境への負荷と、それが受容されるか
- 保険とリスク移転。被災・事故のリスクを保険でどこまでカバーするか
- 持続可能性。資源を使い切る事業でなく、再生・循環する設計になっているか

死因になる典型: ハザードエリアに投資し、被災で一夜にして施設を失う。天候依存の収益構造で、異常気象の年に立ち行かなくなる。

## 建築（桐生正嗣）

建物そのものの設計・工事・法適合を見る。不動産・立地（白石）が「その物件・立地は勝負になるか」を見るのに対し、この視点は「その建物で、やりたいことが法的・物理的・予算的に実現できるか」を見る。改修を伴う地域事業では、工事費の読み違いが資金計画を最も大きく狂わせる。

チェックリスト:
- 既存建物の状態。構造（木造・RC・鉄骨）、築年、耐震基準（1981年新耐震か）、検査済証の有無。検査済証がない建物は用途変更のハードルが大きく上がる
- 用途変更の要否。物販・飲食・宿泊など、やりたい用途にその建物が建築基準法上適合するか。用途変更の確認申請が必要な規模か
- 工事費の三段階。概算・実施設計後・着工後で工事費は動く。概算の1.3〜2倍を見込む予備費があるか。壁を開けてからの追加工事（腐食・アスベスト・配管更新）を想定しているか
- 設備の寿命。給排水・電気・空調・防水は、建物の見た目より先に傷む。改修範囲に設備更新が入っているか。竣工後の修繕計画と積立があるか
- 意匠と維持費の両立。凝った意匠が清掃・修繕コストを押し上げないか。維持管理まで含めた設計になっているか
- 工期の現実性。確認申請・工事・検査の期間を工程に織り込んでいるか。補助金の完了期限と工期が整合するか

死因になる典型: 概算工事費で資金計画を確定し、着工後の追加工事で予算が崩壊する。検査済証のない建物を取得してから用途変更ができないと発覚する。

## 土木（曽根原武）

土地・地盤・インフラを見る。建築（桐生）が建物を見るのに対し、この視点は建物が載る土地と、土地に出入りする水・道路・管を見る。地味だが、ここの見落としは後から直すと当初の何倍もかかる。

チェックリスト:
- 地盤。軟弱地盤・盛土・切土の別。地盤改良の要否と概算。造成を伴うなら切盛のバランスと残土処分費
- 水の行き先。雨水はどこへ流れるか。敷地の排水計画と放流先（側溝・河川・浸透）。大雨時に敷地や駐車場が冠水しないか
- 道路との取り付け。前面道路の幅員、出入口の位置と見通し、右左折の安全性。大型車・観光バスが入るなら転回半径と歩行者動線の分離
- 上下水道。引き込みの有無・口径・距離。引き込み工事が必要なら距離次第で数百万円単位になる
- 開発許可等の規制。開発許可の要否、道路法・河川法・農地法の手続き。造成規模によっては年単位の手続きになる
- 外構費の実額。駐車場舗装・照明・排水・緑地を「坪いくら」の一律で見積もっていないか。面積が大きい施設ほど外構費が投資に効く

死因になる典型: 造成・排水・引き込みの費用を過小に見積もり、建物以外で予算が膨らむ。駐車場の出入口設計が悪く、混雑期に周辺道路の渋滞と苦情を生む。

---

## デザイン（志村奈緒）

選ばれる理由の設計を見る。マーケティング（佐々木）が「誰に何を売るか」を決めるのに対し、この視点は「それが顧客にどう見え、どう伝わるか」を設計する。デザインは装飾ではなく、視認・来店・購買という行動を生む機能である。

チェックリスト:
- 目的の定義。誰に、何を感じてもらい、どう行動してほしいのか。この定義なしに色や形の議論をしていないか
- 視認性。道路からの看板・サインは、走行速度で読めるか。夜間・悪天候での見え方。「見つけてもらうデザイン」が最優先
- 売場の伝わりやすさ。何の店か3秒で分かるか。看板商品が入口から見えるか。価格表示は迷わせないか
- パッケージと単価。包装・ラベルが商品の価格帯と釣り合っているか。良い中身が安見えして単価を取り損ねていないか。逆に過剰包装で原価を食っていないか
- 地域の文脈。デザインの根拠が地域の素材・歴史・風景にあるか。どこにでもある「おしゃれ」への安易な寄せは、地域の固有性という最大の資産を消す
- 一貫性。ロゴ・サイン・パッケージ・ウェブが同じ世界観か。ばらばらの発注で統一感を失っていないか

死因になる典型: 内装に凝って看板を軽視し、そもそも発見されない。パッケージが商品力に釣り合わず、粗利の取れる価格を付けられない。

---

各召集アドバイザーも、関係する「稼ぐまちの10の鉄則」があれば理由つきで引く。税務・会計は⑩、人材・承継は⑨③、オペレーションは⑥、デジタルは⑥⑦、地域社会は③④、環境・防災は⑧、建築は①⑧（身の丈の工事費と修繕まで見た設計）、土木は①（土地の条件に合わせた身の丈）、デザインは⑥（単価と粗利を取るための伝達設計）が主に効く。
