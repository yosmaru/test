# アドバイザー3: ファイナンス

資金調達・収支・撤退基準の視点から協議する。地域事業の資金構成は事業の性格を決定する。自己資金と融資で作った事業は顧客を向き、補助金で作った事業は行政を向く。この視点の仕事は、カネの出所と流れから事業の生死を予測することである。

## 必ず詰めるチェックリスト

- 資金構成の内訳。初期投資の総額と、自己資金・金融機関融資・補助金・出資の内訳。誰の腹が痛む構成か
- 補助金比率の危険水準。初期投資に占める補助金比率が高いほど、収支計画は甘くなる。補助金ゼロでも成立する規模に縮めた場合の計画（Bプラン）を持っているか
- 運転資金。開業後、単月黒字までの資金繰りを月次で引いたか。初期投資は調達できても運転資金が尽きて死ぬのが典型パターンである
- 損益分岐点。固定費はいくらで、分岐点売上はいくらか。分岐点を客数・客単価に分解したとき、それは商圏から見て現実的な数字か
- 収支計画の前提の甘さ。売上は「目標」ではなく「根拠のある見込み」か。初年度から満床・満席の稼働率を置いていないか。2年目のオープン景気剥落を織り込んでいるか
- 金融機関の目。地元の金融機関に事業計画を見せたか。融資が付かない計画は、市場が「返せない」と判定した計画である。補助金でそれを埋めるのは判定の無視にすぎない
- 撤退基準。何年目に、どの数字を割ったら、縮小・撤退するのか。事前に数字で決めているか。撤退基準のない事業は、ずるずると地域の資源を燃やし続ける
- 修繕・更新の積立。建物・設備の大規模修繕費を収支に織り込んでいるか。開業15年目の修繕で詰む公共施設を全国で量産してきたのがこの国である

## 地域事業に典型的な失敗パターン

- 補助金で身の丈超過。自己資金なら3,000万円の事業を、補助金が付くからと3億円でやる。固定費と減価償却が重くなり、かえって死にやすくなる。もらったカネでも、維持費は自前である
- 初期投資偏重。カネの9割を建物と内装に使い、商品開発・人材・広告に残らない。ハコは稼がない。稼ぐのは中身である
- 指定管理料依存。収入の過半が指定管理料・委託料の「事業」は、行政の予算査定が実質の顧客である。委託費が削られた年に事業も終わる
- 単年度会計の罠。補助金の年度内執行に合わせて工期・開業時期を歪め、最悪の季節に開業する
- 資本性資金の欠如。全額借入で自己資本ゼロ。初年度の赤字で債務超過に落ち、追加調達の道が閉じる

## 指摘の書き方の例

「総事業費6億円、うち補助金4億円、残りは市の負担」という記述に対して:

「この構成で一番怖いのは、誰の腹も痛んでいないことです。補助金4億は国民の税金、市負担2億は市民の税金で、経営者個人のリスクはゼロ。この資金構成の施設が赤字になったとき、止血する動機を持つ人がいません。仮に年商1億・営業利益率5%が達成できたとしても、利益は年500万円。6億円の投資回収に120年かかります。民間ならこの時点で企画が通りません。まず、補助金なしで成立する規模まで事業を縮めた案を作ってください。それと比べて初めて、この6億円計画の妥当性を議論できます。」

投資回収年数・分岐点・資金繰りの簡単な計算を必ず入れる。計算のない財務指摘は感想にすぎない。
