# 逆算開発プレイブック（鉄則の実行手順集）

10の鉄則は、違反を指摘するための物差しであると同時に、実行を指導するための手順である。協議会は「鉄則⑤に反しています」で終わってはならない。「では、こう動く」まで教える。このファイルは、鉄則を実行手順に落とすときの教材である。宿題は、この手順の中の具体的なステップとして出す。

出典となる実例はオガール（岩手県紫波町）と紫波マルシェ。開発前に18カ月かけてテナント営業を行い、貸す床がすべて埋まるまで着工しなかった。設計も、当初の鉄筋コンクリート3階建てを木造2階建てに変更し、テナント賃料収入から返済できる建設費まで落とした。作ってから埋める従来型の、完全な逆である。

## 手順1: 逆算開発（鉄則①⑤⑥の複合。事業設計の背骨）

従来型は「規模を決める→建設費が出る→足りない分を補助金で埋める→開業後に売上を祈る」。逆算開発はこの矢印をすべて逆に引く。

1. 手取りの目標から始める。この事業で年にいくらの営業利益（または生活費）が必要かを決める。例: 世帯で年400万円
2. 目標利益と現実的な粗利率から、必要売上を逆算する。例: 粗利率40%・固定費を引いて利益400万円を残すには売上いくらか
3. 必要売上を、客単価×客数に分解し、商圏とテスト販売の実測でその客数が取れるかを検証する（手順2へ）
4. 検証済みの売上見込みから、返済可能な借入額＝投資上限を逆算する。金融機関の目線では、年間返済額は営業キャッシュフローの範囲内。ここで出た投資上限が、建設・改装にかけてよい金額のすべてである
5. 投資上限から、規模と仕様を決める。都会の坪100万円ではなく、地方は坪30〜40万円の民家同様の建築費で考える。それでも収まらなければ、テント張りのマーケット、間借り、既存建物の一部借りから始める。規模が先、カネが後、は禁止。カネが先、規模が後、である
6. 着工条件を決める。オガール型なら「貸す床の全テナントが仮契約で埋まるまで着工しない」。物販なら「事前予約・前売りが◯件に達するまで本投資しない」。この条件を紙に書いてから設計に進む

協議での使い方: 事業者が規模や建設費から話し始めたら、この手順の1に引き戻す。「その規模は、いくらの利益から逆算して出た数字ですか」。答えられなければ、手順1〜3を宿題にする。

## 手順2: 先回り営業の実行手順（鉄則⑤を「やる」）

「作る前に売る」を精神論で終わらせない。需要実証プロトコル（demand-validation.md）のレベル3〜4を取りに行く具体的な動き方である。

1. 買い手のリストを作る。テナント事業なら出店しそうな事業者を実名で20者。物販なら想定顧客に近い人を紹介の連鎖で30人。リストにない「世の中の誰か」は顧客ではない
2. 一枚企画書を作る。場所・広さ・家賃（または商品・価格）・開業時期だけのA4一枚。立派な資料は要らない。判断してもらえる最小限でよい
3. 一人ずつ会って、口頭の意向ではなく「行動」を求める。テナントなら出店意向書か仮契約。物販なら前売り・事前予約・内金。クラウドファンディングも事前コミットの取得手段として有効
4. 断られた理由を全件記録する。家賃が高い、場所が悪い、時期が合わない。この記録が商品設計の修正情報であり、宿題ドリルの提出物になる
5. 目標コミット数に達するまで、本投資をしない。達しないなら、それは市場の答えである。設計を修正するか、撤退する。着工前に分かったことは失敗ではなく、大損の回避である

オガールは、この営業に18カ月かけた。先回り営業は数週間の作業ではなく、開発工程の中で最も時間をかける工程である。急がせる圧力（補助金の年度、首長の任期）から、この工程を守ることが座長と協議会の仕事になる。

## 手順3: 撤退ラインの設定手順（鉄則⑧を「決める」）

1. 指標を3つ以内で選ぶ。売上の計画比、営業キャッシュフロー、現金残高が基本形
2. 数値と期限を入れる。「開業後18カ月で売上が計画比70%未満なら」「現金残高が月商の2カ月分を割ったら」
3. 割ったときの行動を先に決める。縮小（営業日・品目・人員）、業態転換、売却、清算のどれか
4. 関係者と紙で合意する。共同経営者、家族、金融機関、行政（指定管理なら協定に明記）。一人で決めた撤退ラインは、苦しくなると動かせる。だから紙にして他人と共有する
5. 毎月、指標を見る日を決める。撤退ラインは作った日ではなく、見続けた日に機能する

## 手順4: 利益率設計の手順（鉄則⑥を「作る」）

1. 値付けは原価積み上げではなく、顧客の支払い意欲と競合の実勢から決める。テスト販売が一番正確な調査である
2. 目標粗利率を先に決める（小売・直売で35〜45%、飲食で65〜70%が一般的な相場観）。届かない商品は、値上げするか、やめる
3. 「地域だから安く」を禁じる。安売りは、地域の同業の値段も壊す。付加価値を乗せて高く売り、少ない客数で残る構造にする
4. 手数料と見えないコストを引いた「実質粗利」で判断する。販売手数料、決済手数料、送料、廃棄ロス。粗利率は帳面ではなく手残りで測る

## 協議・宿題への組み込み方（必須）

- 鉄則違反を指摘したら、必ず対応する手順の該当ステップを「次の一手」または宿題に落とす。「鉄則⑤に反する」で終わる協議は不完全である。「手順2の1〜3、つまり出店候補20者のリストと一枚企画書を作り、5者に会って意向書の感触を取る」まで書く
- 初期投資の相談は、原則としてすべて手順1（逆算開発）の枠で協議する。規模・建設費が先に出てくる計画は、手順1の1に引き戻す
- 伴走レビューでは、手順のどのステップまで進んだかを追跡する。先回り営業のコミット件数、断られた理由の記録は、完成度スコア「顧客・需要」軸の一次データになる
